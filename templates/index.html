Comment obtenir la clé API Brevo gratuite (Pour Render) ?

300 emails gratuits chaque jour, compatible à 100% avec Render sans aucun blocage !

1

Créez un compte gratuit sur Brevo :

Allez sur brevo.com et inscrivez-vous en 30 secondes (gratuit, sans carte bancaire).

2

Accédez à vos clés API :

Ouvrez directement la page : app.brevo.com/settings/keys/api

3

Générez votre clé :

Cliquez sur « Générer une nouvelle clé API » (choisissez Accès complet ou laissez par défaut) et donnez-lui un nom (ex: MailStorm).

⚠️ ÉTAPE CRUCIALE :

Cliquez immédiatement sur le bouton « Copier » 📋 dans le pop-up avant de le fermer ! Brevo ne réaffiche JAMAIS la clé complète après fermeture. (Une vraie clé fait 89 caractères. Si vous la copiez depuis le tableau de la liste, elle sera coupée à 68 caractères et ne fonctionnera pas).

4

Collez-la dans MailStorm :

Dans l'onglet Paramètres, collez la clé dans le champ Clé API Brevo et cliquez sur Enregistrer !

Guide Gmail : Comment obtenir le mot de passe d'application ?

Pour l'utilisation en local sur votre PC (port SMTP 587).

1

Activer la validation en deux étapes (2-Step Verification)

Si ce n'est pas déjà fait sur votre compte Google, activez la validation en 2 étapes sur : myaccount.google.com/security

2

Accéder aux mots de passe d'application

Ouvrez directement ce lien dans votre navigateur :

Ouvrir Google App Passwords
3

Créer un mot de passe

Écrivez un nom pour l'application (ex: MailStorm ou Python) puis cliquez sur Créer.

4

Copier les 16 lettres

Google affichera un code jaune de 16 lettres (exemple: abcd efgh ijkl mnop). Copiez ce code et collez-le dans l'onglet Paramètres Gmail de MailStorm !

Pourquoi plusieurs emails envoyés à la même personne se regroupent dans Gmail ?

Dans Gmail, il existe une option activée par défaut appelée « Affichage par conversation » (Conversation View). Quand vous envoyez plusieurs emails avec le même objet (sujet) à la même adresse, Gmail les empile dans un seul bloc de discussion.

À savoir :

  • L'objet de vos emails reste 100% propre, exactement tel que vous l'écrivez (aucun code ni texte ajouté).
  • Dans une vraie campagne, chaque destinataire reçoit son propre email donc il n'y aura aucun regroupement chez lui.
  • Si vous testez en envoyant plusieurs fois à votre propre adresse et que vous voulez les voir séparés : allez dans votre boîte Gmail > Paramètres ⚙️ > Afficher tous les paramètres > Général > Affichage par conversation > Désactiver l'affichage par conversation.
